# Satisfying-simulation format — reference analysis (2026-11-13)

Source: 14 reference videos Ali supplied (Bump Theory x6 shorts, CodeCraftedPhysics x3 shorts + 1 long,
Satisfying 2D Sims x4 longs). Take the FORMULA, never clone a specific simulation, layout or melody.

## One-rule formula (every reference video)
1. ONE rule, stated in <= 10 words, on screen from frame 0 ("Each bounce SHRINKS the ball ...and GROWS the wall").
2. Phrase it as a question with a measurable end state ("Can 1,024 balls squeeze into ONE?").
3. Two live counters under the sim (label in small caps, big number). One counts effort, one counts progress.
4. Exponential escalation (x2 per event, SPEED x1 -> x64 time-lapse, colour changes per stage).
5. Doubt beat at 70-90 %: progress drops back / "4 LEFT OUT!" / timer nearly out.
6. SLOW MOTION label for the last 1-2 s, payoff in the final second (flash + one result line).
7. Seamless loop: last 0.5 s cross-fades into the opening state.

## Measured numbers
- Shorts length: Bump Theory 18-29 s (6 videos, mean 26 s). CodeCraftedPhysics 55-64 s.
- First sound event at 0.03-1.1 s (5 of 6 Bump Theory shorts). Motion on screen at frame 0.
- Sound events per second, first quarter -> last quarter: 1.6->9.6, 0.2->4.0, 0.3->1.6, 1.2->2.3.
- Loudness rises 5-14 dB from first to last quarter; loudest moment sits at 83-97 % of the runtime.
- No voice-over anywhere. No music bed in CodeCraftedPhysics (15-27 % true silence); notes come from collisions.
- Long videos: 8-9 min, landscape. Satisfying 2D Sims = 14-20 sims, mostly 20-45 s each;
  CodeCraftedPhysics = 6 sims of 57-97 s. Vertical sim centred, question text left, counter right.

## Layout (vertical 1080x1920)
- y 9-11 %: tiny letter-spaced brand label.  y 12-18 %: two-line question, white + one yellow accent line.
- y 19-21 %: one-line rule in small white text.  y 25-68 %: the simulation.  y 72-78 %: two counters.
- y 78-100 %: EMPTY (Shorts UI covers it). Background: dark navy -> teal gradient with faint grid, or pure black.

## Channel rules derived from this
- Every upload = a new rule (new mechanic), not a re-skin. Keep engine/layout shared, mechanics different.
- Collision-driven notes only from scales we generate; no recognisable copyrighted melodies.
- Weekly landscape compilation (8+ min) built from that week's shorts, chapters named by the question.
