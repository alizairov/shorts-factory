# Lightning never strikes twice? — Chalkboard short (9:16, ~18 s)

Brief: Visual Brain channel short. Guess-first misconception, shown by chalk drawing, no voice, no characters, calm ASMR chalk/room sound, logo + @Visual.Brainer.
Fact: The Empire State Building is struck by lightning about 20–25 times a year (NOAA/NWS: average ~23).

Candidate structures
A. Myth -> wipe -> truth in place: write the saying, cross-check with a drawing, wipe it, write the count. (lesson grammar of the style)
B. Tally first: draw the building, bolts land one by one with tally marks, reveal the saying at the end as the punchline.
C. Two boards: "ONCE" vs "23×" side by side.

Choice: A with B's tally inside it. Write "LIGHTNING NEVER / STRIKES TWICE?" -> draw the Empire State outline -> a first bolt strikes (white chalk) -> wipe the "NEVER" line -> bolts keep landing in orange (accent = the strikes), tally marks counting 1..23 under the building -> write "~23× A YEAR" -> hold, loop back to clean board.
Text on board: 2 lines max at a time. Accent chalk: orange, only for the strikes and their tally.
Sound: chalk scratches per stroke, soft tap per bolt, one wipe swish, quiet room tone, a single low thunder-ish thump on the first bolt only.
