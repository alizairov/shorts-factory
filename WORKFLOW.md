# Weekly workflow (for Claude)

Goal: a monetizable English YouTube Shorts channel of code-animated videos. One Short per day at
22:00 Asia/Tashkent, published through Metricool (brand blogId `7526089`, YouTube connected).

## Rules (YouTube "inauthentic content" policy — keep the channel monetizable)
- Every video is a NEW idea/mechanic. Never re-upload a previous video with only colors/speed changed.
- Rotate formats: Satisfying (physics/math art, little or no text) · Educational (one clear idea, big English text) · Comparison (A vs B, sizes, speeds, numbers).
- Facts and numbers must be correct — check them on the web before rendering.
- Visuals and music are 100% generated by code (no stock footage, no copyrighted music, no real people, no brands/characters).
- `isAiGeneratedContent: false` (nothing realistic/synthetic), `madeForKids: false`.

## Style
- 1080x1920, 30 fps, 15–25 s, H.264 main + AAC, `-movflags +faststart`. Keep each file < 30 MB.
- Gen Z palette in `src/common.py` (`PAL`, `grad()`): #7B61FF #FF5CE1 #FF8A3D #FFE14D #B8FF3C #3CF0FF on deep purple-black.
- Font: "Inter Display Black" via `label()`. Hook text in the top 400 px, payoff/answer near the bottom.
- Music: `music()` synth bed + plucks on events (`pluck`, `note`, `Track`). Strong payoff moment near the end.
- Always render stills (`python3 x.py stills N…`) and look at them before the full render.

## Environment setup
`pip install --break-system-packages pycairo numpy pillow` (ffmpeg and the Inter fonts are usually present).

## Each week
1. `git pull`. Read `videos/*/week*.json` and the "Used ideas" list below — do not repeat.
2. Make 7 new videos → `videos/weekN/` (+ source in `src/wN_*.py`), and `videos/weekN/weekN.json`
   with: day, file, fmt, title (≤ 70 chars, ends with `#shorts`), desc (2 lines + 5 hashtags), tags (5–6), category
   (`EDUCATION` | `SCIENCE_TECHNOLOGY` | `ENTERTAINMENT`).
3. Commit + push to `main`. Check `https://raw.githubusercontent.com/alizairov/shorts-factory/main/videos/weekN/<file>` returns 200.
4. Find the last scheduled date with Metricool `getScheduledPosts`, then schedule the 7 new videos on the following
   7 days at 22:00 Asia/Tashkent with `createScheduledPost` (providers `[{"network":"youtube"}]`,
   `youtubeData.type = "short"`, `privacy = "public"`, media = the raw GitHub URL, `text` = desc).
5. Add the new ideas to "Used ideas" below and push.
